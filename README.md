# FutureView

A modern financial dashboard project with a modular monorepo structure.

## Structure

- `engine/` — Backend (API, data processing, etc.)
- `view/` — Frontend (React dashboard UI)

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/rueijrwu/FutureView.git
   ```
2. Install dependencies for each submodule as needed.
3. See each submodule's README for details.
